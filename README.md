# Mystic's  Fixes
Some fixes originally for Mystic's Monstrosity modpack

## What?
Basically just a collection of hacky fixes or small changes to other mods, either for compatibility or to fix crashes that we decided to release to the public now.

## Mixin Config

Options live in `config/mysticmonstrosityfixes.properties`, in the same style as Lithium. A parent set to false turns off every option under it. `mixin.loading` and `mixin.fixes` start enabled. `mixin.experimental` starts disabled, so the experimental mixins stay off until that line is set to true. The mixin classes are split across `mixin/loading`, `mixin/fixes`, and `mixin/experimental`.

## Experimental

- Cache boot reads of text and JSON from mod jars and resource packs, including namespace lists and directory listings. A changed jar is read again because the cache key includes its size and modified time. Packs inside a world save are left uncached [[code](src/main/java/com/name/mysticmonstrosityfixes/mixin/experimental/bootcache/BootResourceCacheMixin.java), [store](src/main/java/com/name/mysticmonstrosityfixes/BootResourceCache.java)]
- Stitch the block texture atlas into 16384×16384 pages with the vanilla stitcher. A sprite that does not fit opens another page of the same size, and the page index travels in the sprite's U coordinate. ModernFix's fast stitcher still reports that overflow by throwing, and that error line is not logged while the page split is handling it. The stitched pages are saved under `mysticmonstrosityfixes_cache/atlas` and reused on the next boot. Adding or changing a sprite, mod, or resource pack deletes that cache and rebuilds the pages. Page 0 stays a normal 2D texture and lists only the sprites stitched onto it. The block atlas returns every sprite by name as soon as the stitch finishes, so ModernFix dynamic resources can bake a model before the pages are uploaded. A chunk mesh keeps that page in the sprite's U coordinate. With no Iris shader pack, Embeddium stores the vanilla-like float UV, so the page is not packed into a 16-bit texture coordinate. The encoder's clamp back under 1 is undone, and the chunk shader reads floor of that U as the array layer. The menu stage shader keeps Sampler0 as a 2D texture. It draws a chest's own paint and the chest atlas with the same shader as the block meshes, and those textures are not the block atlas. A block sprite on a later page, where U is at least 1, is read from the page array. textureSize stays the bound 2D texture, so the chest texture is not sampled as a page. Binding the block atlas page-0 view also binds the page array. Entity, item, cutout, translucent, and GUI shaders keep Sampler0 as a 2D texture, so a mob skin, a chest atlas, a fluid sheet, a gas texture, and a JEI icon sample the texture that was bound. A shared shader reads a later page only while the block atlas is bound, so a repeating strip at the top of a screen keeps wrapping its own texture when U runs past 1. JEI binds the block atlas and then draws a fluid slot with position_tex_color, so a fluid sprite on a later page, including a Tinkers' Construct potion, is not discarded. Mantle's fluid shader does that same read. A sprite finder covers U from 0 to 1 and skips a sprite that is already on a later page, instead of splitting that cell until the stack overflows. A chest-sheet sprite keeps its own coordinates when a block sprite shares its name, including chest, trapped chest, and ender chest textures that were stitched onto a later block-atlas page. A decorated-pot sheet sprite does the same, so the pot side is not read from that block page. Let There Be Atmosphere's solid ground litter stores the paged U and samples it from the page array, because its own shader binds the block atlas as a 2D texture. A block sprite on a later page, where U is at least 1, is read from a second array sampler. The page array's filter is set on the array itself, so a filter change for one of those other textures is not applied to the array and does not leave that texture incomplete. The layer does not come from another mod's material bits. Turning Embeddium, ModernFix, or Atmosphere off leaves paging on the vanilla sampler, which reads the same U. A sprite on page 0 whose U would be exactly 1 is held just under 1 so it stays on page 0. Solid block fragment shaders, including rendertype shaders added later, are patched in place so Sampler0 is the page array. Cutout and translucent draws keep the bound texture, as described above. Embeddium chunk shaders are patched the same way, including the vertex shaders substituted by Colorful Lighting 2.7.0 and by its feature/modcompat branch. Colorful Lighting replaces the vanilla-like chunk encoder, and the page still rides in the float U that encoder stores. Its block_lit shader samples the page carried in U. While an Iris shader pack is active the atlas stays one 2D texture, because those packs sample a single sampler [[stitch](src/main/java/com/name/mysticmonstrosityfixes/mixin/experimental/blockatlas/BlockAtlasStitchMixin.java), [pages](src/main/java/com/name/mysticmonstrosityfixes/BlockAtlasPages.java), [shader patch](src/main/java/com/name/mysticmonstrosityfixes/BlockAtlasShaderPatch.java), [overflow log](src/main/java/com/name/mysticmonstrosityfixes/AtlasOverflowLogFilter.java)]
